# 梵语百日：先背后懂

## 主题说明

**借助 AI 自学梵语，顺便公开。**

不是课程产品，不为读者设计，不承诺更新频率。仓库为 git log 而生——更新速度等于我背到哪一偈。设成 public 只是省了一步。

AI 在这里干三件事：把散落经验压成课纲、把工具串成流水线、在我拆完一偈后检查六栏表。它不教书，不定句义，不替我背。**背是人的事。**

路线仍是反常识的——**梵文重词不重句**，上来啃语法只会越学越迷糊。

> 前 70 天一个字都别问"为什么"，只问"见过没有"。见过够了，语法自己会浮出来。

## 六条铁律

1. 前 70 天不系统学语法。语法是规范，不是地基。
2. 词汇先于句子。a 结尾词先攻主、属、宾、具、处五格。
3. 四步阅读缺一不可：拆字还原字型 → 找词根分析词尾 → 拆复合词 → **点标点**。
4. 点标点从 Day 15 制度化：给连写文本自己插 danda，阅读难度直降三成。
5. 用汉语骈文的感官读梵语。婉转悠扬，极尽繁华，不做平铺直译。
6. 不用《梵语入门》起步。不会就背，这是学外语的黄金大力丸。

## 100 天地图

| 天 | 主题 | 解锁 |
|---|---|---|
| 1–10 | 字母与声音 | ① 拆字 |
| 11–20 | a 结尾五格视觉记忆 | ② 词尾、④ 点标点 |
| 21–30 | 其余词尾＋复合词入门 | ③ 拆复合词 |
| 31–40 | 四步全开，上《薄伽梵歌》2 章 | 完整四步 |
| 41–50 | 分词与三层复合词 | 三层拆 |
| 51–60 | 阅读速度＋文学感官 | 骈译 |
| 61–70 | 陌生文本自由阅读 | 独立拆读 |
| 71–80 | 语法登场，只解释已见现象 | 规则回灌 |
| 81–90 | 语法回灌，独立作战 | 陌生文本 |
| 91–100 | 结业项目 | 四件交付 |

结业标准不是"能翻译"，是**能独立拆一偈并说清每个判断的依据**。

## 每日固定动作

背 15 min · 词 15 min · 四步 20 min · 点标点 5 min · 骈译 5 min · 三行 3 min

日课按 `模板/day-模板.md` 写，一天一个 commit。六栏表（词形｜词根｜格位/人称｜功能｜义项｜试译）是防 AI 幻觉的护身符。

## 打卡方式

三个动作，一天一次：

```bash
./new-day.sh 2          # 生成 day-002.md，并在打卡表登记日期
# 查课程-逐日.md 的 Day 002 行，照着做：背／词／四步／六栏／骈译／三行
git add . && git commit -m 'day-002 · 拆字与词尾' && git push
```

**勾选规则**：`打卡表.md` 里当天四步＋六栏表＋骈译＋三行都写完才打勾 `x`。没写完就留空——表是进度索引，不是许愿池。每 7 天标 `⟲`，当天回翻任意一条旧记录补一句「后来发现……」。

用 GitHub 网页直接勾选也行，勾完 commit 一次同样的改动。贡献方格是真正的进度条，打卡表只是给人看的。

## 文件

- `课程-逐日.md` — **每天做什么**：100 行逐日表，背哪偈、挑哪些词、开哪几步、锚点问题
- `打卡表.md` — 100 天勾选总表，状态计数与回翻提醒
- `new-day.sh` — 一键生成当日日课并登记日期
- `梵语百日课纲.md` — 课纲：六条铁律、十个十日块、材料工具、避坑
- `模板/day-模板.md` — 每日记录模板
- `day-001.md` — 第一天（已生成，待填）
