# 梵语百日：先背后懂

## 主题说明

**借助 AI 自学梵语，顺便公开。**

不是课程产品，不为读者设计，不承诺更新频率。仓库为 git log 而生——更新速度等于我背到哪一偈。设成 public 只是省了一步。

AI 在这里干三件事：把散落经验压成课纲、把工具串成流水线、在我拆完一偈后检查六栏表。它不教书，不定句义，不替我背。**背是人的事。**

路线仍是反常识的——**梵文重词不重句**，上来啃语法只会越学越迷糊。

> 前 70 天一个字都别问"为什么"，只问"见过没有"。见过够了，语法自己会浮出来。

## 六条铁律

1. 前 70 天不系统学语法。语法是规范，不是地基。
2. 词汇先于句子。a 结尾词先攻主、属、宾、具、处五格。
3. 四步阅读缺一不可：拆字还原字型 → 找词根分析词尾 → 拆复合词 → **点标点**。
4. 点标点从 Day 15 制度化：给连写文本自己插 danda，阅读难度直降三成。
5. 用汉语骈文的感官读梵语。婉转悠扬，极尽繁华，不做平铺直译。
6. 不用《梵语入门》起步。不会就背，这是学外语的黄金大力丸。

## 100 天地图

| 天 | 主题 | 解锁 |
|---|---|---|
| 1–10 | 字母与声音 | ① 拆字 |
| 11–20 | a 结尾五格视觉记忆 | ② 词尾、④ 点标点 |
| 21–30 | 其余词尾＋复合词入门 | ③ 拆复合词 |
| 31–40 | 四步全开，上《薄伽梵歌》2 章 | 完整四步 |
| 41–50 | 分词与三层复合词 | 三层拆 |
| 51–60 | 阅读速度＋文学感官 | 骈译 |
| 61–70 | 陌生文本自由阅读 | 独立拆读 |
| 71–80 | 语法登场，只解释已见现象 | 规则回灌 |
| 81–90 | 语法回灌，独立作战 | 陌生文本 |
| 91–100 | 结业项目 | 四件交付 |

结业标准不是"能翻译"，是**能独立拆一偈并说清每个判断的依据**。

## 每日固定动作（10 分钟版，主线）

背 2 min · 词 3 min · 一步 4 min · 一行 1 min —— 一天只练一个动作。逐日表见 **`十分钟日课.md`**。

原 63 分钟全套保留在 `课程-逐日.md`，作周末加练，不影响打卡。

日课按 `模板/day-模板.md` 写，一天一个 commit。六栏表（词形｜词根｜格位/人称｜功能｜义项｜试译）是防 AI 幻觉的护身符。

## 打卡方式

**一条命令，一个动作：**

```bash
./check.sh          # 勾选最新写好的日课 → 重算进度条 → 连同日课一起 commit + push
```

不用找行、不用改计数、不用写 commit message。脚本会检查 `day-NNN.md` 是否存在，不存在就跳过——先写日课，再打卡。

| 命令 | 用途 |
|---|---|
| `./check.sh` | 日常打卡：自动勾选最新已写的日课并推送 |
| `./check.sh 7` | 补勾指定天（Day 007） |
| `./check.sh 3 4 5` | 一次补勾多天 |
| `./check.sh -u 3` | 撤销 Day 003 的勾选 |
| `./check.sh --refresh` | 在 GitHub 网页勾完后，同步计数与进度条 |
| `./check.sh --status` | 只看进度，不改文件 |
| `./check.sh -m "拆字与词尾"` | 自定义 commit 说明 |
| `./check.sh --no-push` | 只提交，不推送 |

每日循环：`./new-day.sh 2` 开新的一天 → 照 `课程-逐日.md` 的 Day 002 行做 → `./check.sh` 打卡。

**勾选条件**不变：四步＋六栏表＋骈译＋三行都写完才勾。没写完就留空——表是进度索引，不是许愿池。每 7 天标 `⟲`，当天回翻任意一条旧记录补一句「后来发现……」。

贡献方格是真正的进度条，`打卡表.md` 只是给人看的索引。
